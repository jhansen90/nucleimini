🚀 Usage

🔹 Single Target Scan

Scan satu target secara langsung:

python nucleimini.py https://example.com

🔹 Multiple Target Scan

Scan beberapa target dari file "subdo.txt" dan menyimpan hasilnya ke "hasil.txt":

python nucleimini.py -l subdo.txt -o hasil.txt

📄 Input File

"subdo.txt" berisi daftar target, satu target per baris:

https://example.com
https://sub.example.com
https://target.com

📁 Output

Hasil pemindaian akan disimpan pada:

hasil.txt

run tools subfinder

python subfinder.py example.com -o subdo.txt ( biasa )

python subfinder.py example.com -b  -o subdo.txt ( dns brute force )

python python filter.py -f subdo.txt -o live.txt
